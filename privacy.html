Privacy Policy

Personal Sync is used only by its owner. It accesses the owner's own Google account data solely to copy the owner's files between the owner's cloud storage and the owner's own computer.

No data is collected, transmitted to any server operated by the developer, shared with, or sold to anyone. Google user data is used only for this purpose and in line with the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions.
